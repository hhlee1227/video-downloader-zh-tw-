## iPhone 驗收步驟

1. 在 Mac 執行官方簽署、解碼比較，再將已簽署檔傳至 iPhone。確認名稱、圖示與分享選單可見，檢查新增動作均無遺失參數。
2. 使用本人可下載的影音測試：分享單一影片、手動貼上、無效 URL、空白、分享文字含 URL。檢查只有有效網址會傳往解析服務。
3. 服務若仍要求更新，應顯示中文版停止原因，不開啟更新頁或取代中文版；先解決 API 相容性再繼續下載驗收。
4. 服務可用後測影片的各格式、兩個以上媒體多選、音訊至檔案、影片至照片及檔案；逐一實際開啟確認檔案內容與格式，不以通知作為下載證據。
5. 在輸入、格式、多選、儲存位置各階段取消；不得出現成功通知。測拒絕照片權限、斷網、服務失效及儲存失敗，記錄系統或本地提示。
6. 記錄 iOS 版本、平台、測試時間、目的網域、結果與問題；未完成項目繼續標為「待 iPhone 實機驗證」。
